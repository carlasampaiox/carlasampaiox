# Content Lab

Central de conteúdo multimarca: notícias do nicho, referências virais com prévia, calendário, datas importantes, marca, mapa de ideias, métricas e concorrentes, com o Claude sugerindo pautas, legendas e análises.

| Pasta | O que tem |
| --- | --- |
| [`content-lab/`](content-lab/) | a página (artifact), com build e teste de fumaça |
| [`importador/`](importador/) | importação de posts com capa e números reais: Instagram pelo vidIQ (botão, com plano de créditos) e coleta gratuita diária (YouTube, Google Notícias e blogs) |
| [`dados/`](dados/) | resultado da coleta gratuita, gravado pelo GitHub Actions todo dia |
